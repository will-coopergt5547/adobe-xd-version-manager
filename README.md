## Troubleshooting Guide

### The loader will not open

Make sure the download finished successfully and that your Windows account is allowed to run applications from the selected storage location. If the file seems incomplete, download the current build again.

### Download speed is low or the transfer stops

Test the network connection and retry the download. Restricted connectivity, an interrupted transfer, or inadequate disk space may keep the package from completing.

### Package verification reports an error

Delete the incomplete local package and begin the retrieval process again. A package that fails the manager's integrity check should not be used for setup.

### Windows prevents setup from continuing

Check the permissions associated with your Windows account and the folder containing the loader. If installation requires administrator access, comply with the device policies set by your organization before proceeding.

### The offline workflow cannot locate the installer

Verify that all installer files finished downloading and are still stored in the expected local directory. Do not rename or relocate package contents while setup is running.

### Uninstallation does not remove everything

Run the provided uninstall process first and restart Windows if requested. Before manually deleting anything, inspect the installation directory for files that remain.

Available builds and packages are labeled by version in the manager. Check this information before downloading or beginning the setup process.

### Can an earlier version be restored?

### Where is download or error status shown?

The loader displays progress while packages are being retrieved. For more information, read the messages shown by the utility and record any error details before attempting another download.

### What operating systems are supported?

The project targets Windows systems. Actual compatibility may depend on the computer's configuration, user permissions, and the Adobe XD package selected for installation.

### What needs to be reviewed before setup?

Check the chosen version, available disk space, Windows permissions, and the Adobe terms and licensing conditions that apply to your installation and use.
